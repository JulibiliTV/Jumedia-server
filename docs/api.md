# Jumedia 接口参考

## 账号弹幕设置

`GET /x/v2/dm/web/view?type=1&oid=1` 返回 protobuf，外层字段 10 是当前账号的播放设置。登录前可以用此请求读取默认值。账号设置独立于视频，登录后可通过 `POST /x/v2/dm/web/config` 携带 CSRF 更新指定参数，未提交的设置继续保留。

| 设置 | 读取字段 | 写入参数 |
| --- | --- | --- |
| 弹幕开关 | 字段 28 的取值为 1（开启）、2（少量）、3（关闭）；字段 1 为旧版布尔开关 | `dm_switch_state`，旧客户端可用 `dm_switch` |
| 显示区域 | 25，旧字段 12 | `dm_area_v2`，旧参数 `dmarea`。取值 0–100，0 表示全屏；少量模式使用顶部 10%，保留原区域设置 |
| 固定弹幕 | 24 表示顶部与底部均开启；4、6 分别表示顶部、底部 | `blocktop_bottom` 同时设置两项，也可单独提交 `blocktop`、`blockbottom` |
| 避让字幕、人像防遮挡 | 9、10 | `preventshade`、`dmask` |

一次提交中同时包含新旧参数时，以新参数为准；两种客户端读取同一份账号设置。调整本机开关后是否自动上传由客户端决定。

## 弹幕分段

分段接口使用 protobuf。`X-Jumedia-Danmaku-Pending: true` 表示服务端正在获取弹幕，客户端每 2 秒重新请求，直到获取完成。缺少此响应头时按已完成处理。

## 媒体数据源

个人与管理端的 `datasource/test`、`datasource/save` 均接受 `type=emby`、`type=jellyfin`、`type=fntv`（飞牛影视）。新建时省略 `type` 默认使用 Emby，编辑时省略则沿用已保存的类型。已保存的数据源类型固定。

保存时传入 `sync_now=false` 表示仅保存连接，省略时保留立即同步行为。`proxy_playback` 控制代理播放，编辑时省略此字段会保留原设置。

飞牛影视使用影视账号、密码和可访问的 HTTP/HTTPS 服务地址，支持反向代理子路径；地址末尾的 `/v` 可省略。登录优先使用密码摘要接口，仅在该接口返回 HTTP 404/405 时尝试旧版登录接口。密码加密保存，编辑时留空保留；访问令牌仅缓存在服务端内存中。

飞牛媒体库支持电影、剧集和视频的整库同步、浏览与手动导入，剧集按季集顺序生成分 P，封面由服务端获取。同步沿用站点的请求速率和并发设置；个人数据源仍受私网访问设置限制。原文件通过 Jumedia 代理提供，保留 Range/HEAD 行为，不请求上游转码。飞牛暂不提供直连播放，显式传入 `proxy_playback=false` 返回 `code=-400`；省略时使用代理播放。浏览器 Mock 会提示改用连接真实服务端的网页，不直接向飞牛发送账号信息。

| 个人媒体库操作 | 请求 | 参数 |
| --- | --- | --- |
| 浏览 | `GET /x/web/datasource/items` | `id`、`library`、`keyword`、`pn`、`ps` |
| 导入 | `POST /x/web/datasource/import` | `id`、`library`、JSON 字符串数组 `item_ids` 和会话 `csrf` |
